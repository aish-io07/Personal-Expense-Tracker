# 💰 Personal Expense Tracker

A simple and interactive personal expense tracking dashboard built using Python, Streamlit, SQLite, Pandas and Plotly.

## ✨ Features

- 💰 Track personal expenses
- 📊 View total spending and highest expense
- 📅 Filter expenses by date
- 🏷️ Filter expenses by category
- 📈 View monthly spending trends
- 🥧 Visualize category-wise spending
- 🎯 Set and monitor a monthly budget
- 🚨 Get budget warnings when spending is high
- 🗑️ Delete expenses when needed
- 💾 Store expense data using SQLite

## 🛠️ Technologies Used

- Python
- Streamlit
- SQLite
- Pandas
- Plotly

## 📊 Dashboard

The dashboard provides an overview of spending with charts, statistics, filters and budget tracking.
